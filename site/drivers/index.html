Installing any of them

  1. 1

    Download

    Get the driver's .c4z from its page. Each release lists a SHA-256 checksum next to the file.

  2. 2

    Add it in Composer Pro

    Driver → Add or Update Driver or Agent, then select the file. On the Search tab, tick Local and search for DirectorLink.

  3. 3

    Keep the file name

    Composer knows a driver by its file name. A second download saved as … (1).c4z installs as a separate driver instead of updating: delete older downloads first.

Good to know

  • Open source

    Apache License 2.0: use, change and share them, in commercial installations too. The source of each is on GitHub.

  • Nothing comes to us

    A driver talks only to its device, or to the maker's own cloud where the device needs it. It sends nothing to DirectorLink and collects no usage data.

  • Community support

    Best effort, in the open: report a problem from the driver's page. Each driver's page says what it was tested on.
