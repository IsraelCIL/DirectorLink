DirectorLink Drivers

DirectorLink · UniFi Protect for Control4

Free, open-source Control4 drivers for UniFi Protect cameras and doorbells. Add the hub, paste an API key, and every camera and doorbell on the console is in Control4, named as in UniFi Protect. They talk straight to your console with Ubiquiti's official Protect Integration API: no cloud, no extra hardware and no subscription.

Free. No subscription, no license key, no account with us.

Download the drivers Release notes and checksums Source and full guide

Made by DirectorLink, the open-source management layer for Control4 homes. Works on its own: DirectorLink is not required.

Field reports wanted. The drivers follow Ubiquiti's published API and pass their tests against recorded answers from real consoles, but no installer has reported on them from a real UniFi system yet. If you install them, please send the log.

Control4 plays H.264 video only: if Enhanced Encoding (H.265) is on for a camera in UniFi Protect, turn it off for that camera.

Two drivers, install both

Driver in Composer File What it does
DirectorLink · UniFi Protect DirectorLink-UniFi-Protect.c4z Added once (it shows as UniFi Protect Hub): connects to the console with its API key, adds every camera, serves their pictures, and gives the home one alerts tile.
DirectorLink · UniFi Protect Camera DirectorLink-UniFi-Protect-Camera.c4z One per camera or doorbell, added by the hub: video, pictures, detections, alerts, rings and programming.

What it needs

  • A Control4 controller on OS 3.3 or newer, and Composer Pro. Live video needs OS 3.3.2 or newer; on 3.3.0 and 3.3.1 pictures, alerts and rings work.
  • A UniFi console running UniFi Protect 5.3 or newer: Dream Machine (Pro, SE, Pro Max), UNVR, UNVR Pro, Cloud Key Gen2 Plus and the other consoles that run Protect.
  • An API key made on the console. No UniFi username or password is needed.
  • The console reachable from the Control4 controller on port 443.

Setup in three steps

  1. 1

    Make an API key

    On the UniFi console: Settings → Control Plane → Integrations → Create API Key. Copy the key.

  2. 2

    Connect the hub

    Add DirectorLink · UniFi Protect in Composer Pro, enter the console's address and paste the API key. Status says Connected and shows the Protect version.

  3. 3

    Add the cameras

    Run Actions → Add New Cameras, then drag each camera and doorbell to its room.

Pictures, live video (RTSP or RTSPS), alerts and every setting are on the drivers' Documentation tab in Composer and in the full guide.

With DirectorLink

DirectorLink 1.10 and newer shows these cameras and doorbells with their pictures, their alerts and their doorbell rings, with nothing to set up. The API key never leaves the controller: DirectorLink takes the pictures the way Control4 apps do, from the hub.

Privacy and support

  • The drivers talk only to the UniFi console on your home network. They send nothing to DirectorLink or to Ubiquiti's cloud and collect no usage data. The API key stays in your Control4 project, and reports and logs never show it, stream tokens or picture passwords.
  • Keep the exact file names: a browser's … (1).c4z copy installs as a separate driver instead of updating.
  • Community-supported, best effort. Report a problem with the console model, its Protect version, your Control4 OS version and the hub's Print Diagnostics.
